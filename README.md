## 🎮 Projetos Atuais
* **Simulador TCG:** Um jogo de cartas em turnos localizado na pasta `/jogos`.

## 🧠 Funcionamento do Simulador TCG
O programa simula um combate direto entre duas cartas em que envolve dois atributos: ataque e defesa. o jogo consiste em turnos até que o hp de um dos jogadores chegue a zero. O usuário deverá insirir o nome e os valores para o ataque e para o hp.

## 🚀 Como Rodar o Jogo
1. Entre na pasta `jogos`.
2. Execute o comando: `python simulador_tcg.py`

## 📚 Respostas Teóricas
### 1. Qual é a principal diferença prática entre usar um laço `for` e um laço `while`? Por que o `while` foi a melhor escolha para este duelo?
**resposta** O laço `for` é usado para quando se sabe um número fechado de laços o código deve rodar. De forma diferente o 'while' funciona quando não há um número determinado de laços para rodar, por esse motivo esse recurso foi usado para o simulador de cartas, pois nao se sabe em quantos turnos um dos jogadores chegará no hp=0

### 2. Para que serve a palavra-chave return dentro de uma função? O que acontece se uma função fizer um cálculo matemático mas não possuir o return?
**reposta** O `return` serve para finalizar uma função e devolver o valor gerado por ela, casa nao haja a função devolve como vazia: `none`.
 
### 3. O que é um " loop infinito " e como podemos evita-lo ao construir uma estrutura
**resposta** O loop infinito ocorre sempre quando uma condição se mantém verdadeira (`tue`) para sempre. Para evita-lo deve-se garantir que uma condição de parada seja atingida.
