## 🎮 Projetos Atuais
* **Simulador TCG:** Um jogo de cartas em turnos localizado na pasta `/jogos`.

## 🧠 Funcionamento do Simulador TCG
O programa simula um combate direto entre duas cartas em que envolve dois atributos: ataque e defesa. o jogo consiste em turnos até que o hp de um dos jogadores chegue a zero.

## 🚀 Como Rodar o Jogo
1. Entre na pasta `jogos`.
2. Execute o comando: `python simulador_tcg.py`
